# Degen Chat Server

This is a server application built with Node.js and Express.

## Prerequisites

Make sure you have the following installed on your machine:

- [Node.js](https://nodejs.org/)
- [npm](https://www.npmjs.com/)

## Installation

1. Clone the repository:

   ```sh
   git clone https://github.com/your-username/degen-chat-server.git


2. Navigate to the project directory:
sh
cd degen-chat-server


3. Install the dependencies:

sh

npm install

# Running the Server
To start the server, run the following command in the terminal:
 ```sh

# Accessing the Server
Open your web browser and navigate to http://localhost:3000. You should see a message saying "good to go" indicating that the server is running successfully.
